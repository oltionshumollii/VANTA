# VANTA — Fictional SaaS Website

> A premium fictional SaaS/product website created as a web development and UI/UX demonstration project.

![VANTA Preview](https://placehold.co/1200x630/08090b/caff45?text=VANTA+%E2%80%94+Fictional+Product+Concept)

## Overview

**VANTA** is a fictional digital workspace concept designed to demonstrate how a modern SaaS landing page can be structured, designed and developed from scratch.

The project focuses on:

- Premium dark-mode visual design
- Strong typography and spacing
- Responsive layouts
- Product storytelling
- SaaS-style pricing
- Dashboard UI mockups
- FAQ interactions
- Clear demo/fictitious-project disclosure
- Clean HTML/CSS/JavaScript structure

## Important Notice

**VANTA is NOT a real company, product, client or service.**

Everything presented in this project is fictional and exists only for demonstration purposes, including:

- Brand identity

## Design Direction

The visual direction is intentionally minimal and premium:

- Dark interface
- Lime accent color
- High-contrast typography
- Large editorial headlines
- Rounded cards
- Subtle borders
- Soft ambient glow
- Minimal motion
- Responsive layout

The goal was to make the website feel closer to a polished modern product than a basic HTML exercise.
